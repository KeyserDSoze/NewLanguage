# Legacy Source Notes

This document summarizes the historical spreadsheet **Nuova lingua STRING.xlsx**. It is not normative.

## Material preserved as useful design input

The spreadsheet contains:

- subject–verb–complement sentence order;
- invariant verb use across personal subjects in basic examples;
- explicit negation;
- yes/no question patterns;
- interrogative words;
- pronoun experiments;
- article and demonstrative systems;
- preposition inventories;
- noun plural experiments;
- several verb tense/aspect systems;
- modal and auxiliary verb experiments;
- vocabulary inspired partly by English pronunciation.

## Important conflicts with the current specification

Several legacy forms are incompatible with current STRING principles.

Examples include forms with:

- adjacent vowels, such as legacy `ai`;
- consonant clusters, such as legacy `strong`, `work`, `bring`, `swim`;
- English-derived spellings that are not strictly one-symbol/one-sound;
- competing verb paradigms in different spreadsheet sheets;
- grammatical gender in articles;
- plural suffix rules that can produce illegal clusters.

These items remain valuable evidence of the original design intent, but they must be normalized rather than copied.

## Historical sentence patterns

The spreadsheet explicitly records the following conceptual structures:

```text
affirmative: subject + verb + complement
negative:    subject + negation + verb + complement
question:    verb + subject + complement?
```

Some example cells differ from the written negative formula, so the new grammar should resolve that inconsistency rather than reproduce it.

## Historical verbal systems

The workbook contains at least two different approaches:

- suffix-based derivation for participles and past forms;
- auxiliary/particle-based tense constructions.

Because STRING now prioritizes minimal grammar, the normative specification should select one small regular system rather than merge both.

## Editorial rule for legacy data

A legacy rule becomes normative only after it has been checked against:

1. current phonotactics;
2. one-symbol/one-sound orthography;
3. grammatical simplicity;
4. absence of unnecessary gender/person/number agreement;
5. consistency with the rest of the grammar.
