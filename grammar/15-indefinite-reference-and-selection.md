# 15 — Indefinite Reference and Selection

STRING avoids large paradigms of indefinite pronouns.

Instead, a small set of ordinary invariant words combines transparently.

## 1. Thing and person — WORKING STANDARD

Two general reference nouns are:

| STRING | Meaning |
|---|---|
| `tin` | thing |
| `yuman` | human / person |

`tin` comes directly from English **thing** after the regular STRING sound mapping.

`yuman` is a reviewed shortening of the mechanically repaired English **human** pronunciation.

Neither word changes for number.

## 2. Any — WORKING STANDARD

`heni` means **any**.

```text
heni buk
any book / any books
```

It does not change for count, gender, or number.

## 3. Each and every — CONFIRMED

STRING uses one word, `hic`, for the distributive meanings English commonly divides between **each** and **every**.

```text
hic yuman
each person / every person

hic tin
each thing / every thing
```

When the English distinction between *each* and *every* does not change the practical meaning, STRING does not encode it.

A more explicit phrase may be used when a special distributive interpretation must be emphasized.

## 4. Both — WORKING STANDARD

`bot` means **both**.

```text
bot yuman
both people
```

The following noun remains unchanged.

## 5. Same — WORKING STANDARD

`sem` means **same**.

```text
sem buk
the same book / same books
```

STRING does not require a definite article before `sem`.

## 6. Somebody and someone — CONFIRMED

Use:

```text
sam yuman
```

This covers English **someone** and **somebody**.

No separate pronoun is needed.

## 7. Anybody and anyone — CONFIRMED

Use:

```text
heni yuman
```

This covers English **anyone** and **anybody**.

## 8. Nobody and no one — CONFIRMED

Use:

```text
nan yuman
```

This means **no person / nobody / no one**.

STRING does not need three separate lexical forms.

## 9. Everybody and everyone — CONFIRMED

Use:

```text
hol yuman
```

This means **all people / everybody / everyone**.

## 10. Something — CONFIRMED

Use:

```text
sam tin
```

This means **something / some thing**.

## 11. Anything — CONFIRMED

Use:

```text
heni tin
```

This means **anything / any thing**.

## 12. Nothing — CONFIRMED

Use:

```text
nan tin
```

This means **nothing / no thing**.

## 13. Everything — CONFIRMED

Use:

```text
hol tin
```

This means **everything / all things**.

## 14. Another — CONFIRMED

Use:

```text
wan hader + NOUN
```

Example:

```text
wan hader buk
another book / one other book
```

No special article or suffix is required.

## 15. What or which + noun — WORKING STANDARD

`wat` before a noun asks for the identity or selection of that noun.

```text
wat buk?
what book? / which book?
```

STRING does not require a grammatical distinction between English **what** and **which** when both ask the listener to identify a member or kind.

## 16. Whose — CONFIRMED

Possession already uses:

```text
POSSESSOR + NOUN
```

Therefore the interrogative possessor is simply:

```text
hu + NOUN
```

Example:

```text
hu buk?
whose book?
```

No separate word equivalent to English **whose** is needed.

## 17. How many — CONFIRMED

Use the ordinary question word plus the ordinary quantifier:

```text
ha meni + NOUN
```

Example:

```text
ha meni buk?
how many books?
```

The noun remains unchanged.

## 18. Indefinite reference remains compositional — CONFIRMED

Do not add separate dictionary words for:

- someone;
- somebody;
- anyone;
- anybody;
- nobody;
- no one;
- something;
- anything;
- nothing;
- everything;
- everyone;
- everybody;

unless a future lexical meaning is genuinely different from the transparent STRING phrase.

The default is composition, not memorization.
