# 16 — Verb Complements and Semantic Roles

STRING keeps the relation between a verb and its participants explicit.

It does not require noun case endings or special object pronouns.

## 1. Direct object — CONFIRMED

The ordinary direct object follows the lexical verb.

```text
SUBJECT + PREDICATE + OBJECT
```

Example:

```text
mi si buk.
I see a book / books.
```

Pronouns use the same position:

```text
mi si yu.
I see you.
```

## 2. Recipient or destination — CONFIRMED

Use `tu` for a recipient, destination, or goal.

```text
VERB + THING + tu + RECIPIENT
```

Example:

```text
mi giv buk tu yu.
I give a book to you.
```

The pronoun `yu` does not change after `tu`.

## 3. No double-object grammar — CONFIRMED

English can say both:

```text
give the book to me
give me the book
```

STRING keeps one canonical pattern:

```text
giv buk tu mi
```

There is no second grammatical object order to memorize.

## 4. Source — CONFIRMED

Use `fam` for a source or starting point.

```text
... fam + SOURCE
```

The same relation word is used whether the source is spatial, temporal, or abstract when the meaning is clear.

## 5. Companion or instrument — CONFIRMED

Use `wid` for accompaniment or an instrument.

```text
... wid + NOUN PHRASE
```

STRING does not add instrumental case endings.

## 6. Agent relation — WORKING STANDARD

`ba` can mark an explicit agent or means relation when a clause or lexical construction needs one.

STRING nevertheless prefers a normal active clause when the agent is known.

The language does not require passive verb morphology merely to express an agent with **by**.

## 7. Multiple complements — WORKING STANDARD

Place the direct object immediately after the lexical verb.

Place additional relational phrases after it.

Canonical pattern:

```text
SUBJECT + PREDICATE + OBJECT + RELATIONAL PHRASE(S)
```

This ordering reduces ambiguity about which noun is the direct object.

## 8. Clause complement — CONFIRMED

A complete proposition used as a complement is introduced by `dat`.

```text
SUBJECT + PREDICATE + dat + CLAUSE
```

This is the same content-clause rule defined earlier.

## 9. Verb complement without English "to" — CONFIRMED

A verb that semantically selects another action can be followed directly by that verb.

```text
mi nid go.
I need to go.

mi won go.
I want to go.
```

Do not insert preposition `tu` merely because English writes infinitive **to**.

`tu` is used for a real recipient, destination, or goal relation, not as an automatic infinitive marker.

## 10. Optional object — WORKING STANDARD

A verb's object may be omitted when:

- the lexical meaning permits it; and
- the intended object is irrelevant or obvious from context.

Omission does not change the verb form.

The dictionary can document when a lexical verb conventionally requires a complement.

## 11. No case declension — CONFIRMED

Nouns and pronouns never change form because they are:

- subject;
- direct object;
- recipient;
- source;
- companion;
- instrument;
- object of another preposition.

Word order and explicit relation words carry these roles.
