# 10 — Word Classes and Word Formation

STRING minimizes grammatical morphology. A word should not need a different ending merely because it appears in a different sentence.

## 1. No grammatical word-class endings — CONFIRMED

STRING does not require special endings meaning:

- noun;
- verb;
- adjective;
- adverb;
- agent;
- abstract noun;
- participle.

A word's lexical meaning and syntactic position determine how it functions.

## 2. One accepted form may have related functions — WORKING STANDARD

When closely related uses are easy to understand from position, one dictionary entry may document more than one word-class function.

This avoids creating artificial pairs whose only purpose would be grammatical labeling.

However, STRING does **not** assume that every noun can automatically be used as every possible verb, or vice versa. The dictionary documents conventional meanings.

## 3. Inflection and derivation are different — CONFIRMED

Inflection is avoided whenever grammar can express the same information with invariant words.

For example:

- no plural suffix;
- no person suffix;
- no tense suffix;
- no participle suffix;
- no adjective agreement.

A genuinely new lexical concept may still receive its own dictionary entry.

## 4. English suffixes are not copied mechanically — CONFIRMED

English endings such as:

```text
-s
-ed
-ing
-er
-est
-ly
-ness
-ment
-tion
-ity
```

do not become automatic STRING grammar.

The underlying meaning is expressed with normal STRING grammar or with a separately accepted lexical word.

## 5. Compounding before derivation — CONFIRMED

When an unfamiliar concept can be expressed clearly by combining accepted words, STRING prefers the transparent multi-word expression.

```text
MODIFIER + HEAD
```

The component words remain unchanged.

Only frequent, stable combinations should later be considered for lexicalization as one dictionary word.

## 6. Negation is normally compositional — CONFIRMED

Do not create a separate lexical opposite merely because English has a prefixed form.

Use `not` when logical negation expresses the intended meaning correctly.

A lexical antonym may still exist when its meaning is conventional and not equivalent to simple negation.

## 7. Comparison is grammatical, not derivational — CONFIRMED

Do not create adjective variants for comparative and superlative degree.

Use:

```text
mor + MODIFIER
les + MODIFIER
mos + MODIFIER
lis + MODIFIER
```

The base word remains unchanged.

## 8. Agent and role nouns — PROVISIONAL

STRING will prefer transparent phrases before introducing a productive agent suffix comparable to English `-er`.

If a profession, role, or agent concept is highly frequent, it may receive its own lexical entry derived from its English pronunciation.

No agent suffix is currently mandatory.

## 9. Abstract nouns — PROVISIONAL

STRING does not currently define productive equivalents of English `-ness`, `-ity`, or `-tion`.

Frequent abstract concepts are ordinary dictionary entries.

Less frequent concepts should first be expressed compositionally when possible.

## 10. Collision rule still applies — CONFIRMED

A derived or lexicalized form must pass the same collision and phonotactic checks as every other dictionary entry.

Word formation never permits:

- silent letters;
- internal consonant clusters;
- adjacent vowels;
- illegal spelling;
- a duplicate unrelated accepted headword.

## 11. Dictionary authority — CONFIRMED

The dictionary determines which lexicalized meanings are accepted.

Grammar explains how accepted words combine; it does not silently create an unlimited hidden dictionary.
