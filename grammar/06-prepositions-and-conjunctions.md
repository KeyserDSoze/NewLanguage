# 06 — Prepositions and Conjunctions

## 1. Prepositions do not inflect — CONFIRMED

A preposition is an invariant word placed before its complement.

```text
PREPOSITION + NOUN PHRASE
```

Nouns and pronouns do not change case after a preposition.

## 2. Core prepositions — WORKING STANDARD

The core inventory is intentionally small.

| STRING | Main meaning |
|---|---|
| `hat` | at |
| `hin` | in |
| `hon` | on |
| `tu` | to |
| `fam` | from |
| `for` | for |
| `wid` | with |
| `ba` | by |
| `hava` | of / explicit relation |
| `nir` | near |
| `turu` | through |

A single preposition may cover closely related spatial, temporal, or abstract uses when no ambiguity is created.

STRING should not create a new grammatical preposition merely to mirror every English idiom.

## 3. Possession normally needs no "of" — CONFIRMED

Simple possession uses possessor + noun:

```text
mi buk
my book
```

`hava` is therefore reserved for cases where an explicit `of`-type relation is useful.

## 4. Negating a relation — CONFIRMED

Do not create separate negative prepositions.

Use `not` before the preposition or relational phrase:

```text
not hin
not in

not wid
without / not with
```

The exact interpretation follows the surrounding sentence.

This replaces the historical design's many separate `not X` lexical entries.

## 5. Core temporal relations — WORKING STANDARD

Time uses ordinary invariant prepositions.

| STRING | Meaning |
|---|---|
| `bifor` | before |
| `hafer` | after |
| `durin` | during |
| `til` | until / till |
| `fam` | from / since a starting point |

The same general relational grammar is used for space and time.

## 6. Complex relations — CONFIRMED

STRING prefers compositional phrases over memorizing a very large closed list of prepositions.

A precise concept such as `in front of`, `on top of`, or `far from` should be built from ordinary accepted lexical words when those words exist.

The dictionary may later lexicalize extremely frequent combinations, but grammar does not require them.

## 7. Core conjunctions — WORKING STANDARD

| STRING | Meaning |
|---|---|
| `han` | and |
| `hor` | or |
| `bat` | but |
| `hif` | if |
| `bikaz` | because |
| `so` | so / therefore in ordinary coordination |

Conjunctions are invariant.

## 8. Coordination — CONFIRMED

A conjunction appears between the units it joins.

```text
X han Y
X and Y

X hor Y
X or Y
```

The joined units may be words, noun phrases, predicates, or clauses when the meaning is clear.

## 9. Subordination — WORKING STANDARD

`hif` introduces a condition.

`bikaz` introduces a reason.

STRING avoids special verb forms inside subordinate clauses; normal clause grammar continues to apply.
