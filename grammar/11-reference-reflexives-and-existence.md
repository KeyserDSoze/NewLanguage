# 11 — Reference, Reflexives, and Existence

STRING prefers reusable ordinary words over large pronoun paradigms.

## 1. Here and there — CONFIRMED

The basic place words are:

| STRING | Meaning |
|---|---|
| `hir` | here |
| `der` | there |

They are invariant.

```text
mi bi hir.
I am here.

da bi der.
He / she / it is there.
```

## 2. Existential "there is / there are" — WORKING STANDARD

`der` can serve as the subject of an existential clause.

```text
der bi + NOUN PHRASE
```

Example:

```text
der bi buk.
There is a book. / There are books.
```

The noun does not change for number.

Quantity can be stated when needed:

```text
der bi tiri buk.
There are three books.
```

## 3. Negative existence — CONFIRMED

Negate the normal predicate:

```text
der not bi buk.
There is no book. / There are no books.
```

A separate negative existential verb is unnecessary.

## 4. Existential questions — CONFIRMED

Use the normal question inversion rule:

```text
bi der buk?
Is there a book? / Are there books?
```

No special question construction is needed.

## 5. Reflexive reference — CONFIRMED

`selaf` means **self**.

Combine it with an ordinary pronoun:

| STRING | Meaning |
|---|---|
| `mi selaf` | myself |
| `yu selaf` | yourself / yourselves |
| `da selaf` | himself / herself / itself |
| `wi selaf` | ourselves |
| `de selaf` | themselves |

The pronoun itself never changes form.

Example:

```text
mi si mi selaf.
I see myself.
```

## 6. Emphatic self — WORKING STANDARD

The same `PRONOUN + selaf` expression may emphasize the referent when word order makes the role clear.

STRING does not create a second set of emphatic pronouns.

## 7. Other — CONFIRMED

`hader` means **other**.

It is invariant and can modify a noun or stand in a context where the omitted noun is obvious.

## 8. Reciprocal reference — WORKING STANDARD

`wan hader` means **one another / each other**.

Example pattern:

```text
de VERB wan hader.
They VERB one another.
```

STRING does not create person-specific reciprocal pronouns.

## 9. Generic "they" — WORKING STANDARD

`de` may be used for an unspecified human or group agent when English might use generic **they**, **people**, or an agentless passive.

This is preferred over introducing passive verb morphology merely to hide an unknown agent.

Use this only when the intended agent is plausibly human or agentive and the meaning remains clear.

## 10. Reference economy — CONFIRMED

Do not repeat grammatical information that is already clear.

However, ordinary declarative subjects are not silently dropped merely to shorten a sentence.

Subject omission is standard for:

- direct commands;
- tightly coordinated clauses with the same obvious subject.

Elsewhere, keep the subject explicit when omission could create uncertainty.
