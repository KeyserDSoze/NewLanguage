# 13 — Core Sentence Patterns

This chapter deliberately repeats rules from earlier chapters.

Its purpose is to provide a compact set of patterns that can be learned directly without requiring the reader to infer missing grammar.

English translations are meaning guides. They do not imply that STRING copies English grammar.

## 1. Simple statement

```text
SUBJECT + VERB + OBJECT
```

Example:

```text
mi si buk.
I see a book / books.
```

The verb does not change.

## 2. Pronoun as object

```text
yu si mi.
You see me.
```

`mi` has the same form as subject and object.

The same rule applies to all personal pronouns.

## 3. Copula plus description

```text
SUBJECT + bi + DESCRIPTION
```

Example:

```text
buk bi gud.
The book is good. / Books are good.
```

There is no gender or number agreement.

## 4. Location

```text
mi bi hir.
I am here.

da bi der.
He / she / it is there.
```

## 5. Possession inside a noun phrase

```text
POSSESSOR + NOUN
```

Example:

```text
mi buk
my book
```

In a sentence:

```text
mi buk bi gud.
My book is good.
```

No possessive ending is added.

## 6. Quantity

```text
NUMBER + NOUN
```

Example:

```text
tiri buk
three books
```

The noun remains `buk`, not a special plural form.

## 7. Unmarked verb

```text
mi go.
I go. / I am going, when context makes ordinary present time sufficient.
```

Use explicit aspect only when the distinction matters.

## 8. Past

```text
SUBJECT + did + VERB
```

Example:

```text
mi did go.
I went.
```

The lexical verb remains `go`.

## 9. Future

```text
SUBJECT + wil + VERB
```

Example:

```text
mi wil go.
I will go.
```

## 10. Conditional or hypothetical

```text
SUBJECT + wud + VERB
```

Example:

```text
mi wud go.
I would go.
```

## 11. Progressive

```text
SUBJECT + bi + VERB
```

Example:

```text
mi bi go.
I am going.
```

Past progressive:

```text
mi did bi go.
I was going.
```

## 12. Perfect

```text
SUBJECT + hav + VERB
```

Example:

```text
mi hav go.
I have gone.
```

Past perfect:

```text
mi did hav go.
I had gone.
```

## 13. Perfect progressive

```text
SUBJECT + [TENSE] + hav + bi + VERB
```

Example:

```text
mi did hav bi go.
I had been going.
```

No word changes form.

## 14. Negation

Without an explicit tense word:

```text
SUBJECT + not + PREDICATE
```

Example:

```text
mi not go.
I do not go.
```

With an explicit tense word:

```text
SUBJECT + TENSE + not + PREDICATE
```

Example:

```text
mi did not go.
I did not go.
```

## 15. Yes/no question

Move the first predicate word before the subject.

Statement:

```text
yu did go.
You went.
```

Question:

```text
did yu go?
Did you go?
```

No extra `do` auxiliary is added.

## 16. Present question with a lexical verb

```text
go yu?
Do you go?
```

The question mark helps in writing, but the word order already marks the question.

## 17. Question word

```text
QUESTION-WORD + normal question order
```

Examples:

```text
wat si yu?
What do you see?

wer go yu?
Where do you go?

wen wil yu go?
When will you go?

ha bi yu?
How are you?
```

## 18. Command

Remove the explicit subject.

```text
go!
Go!
```

Negative command:

```text
not go!
Do not go!
```

Polite command:

```text
piliz go.
Please go.
```

## 19. Demonstrative noun phrase

```text
dis buk
this book / these books

dat buk
that book / those books
```

The demonstrative does not change for number.

## 20. Comparison

```text
A + bi + mor/les + MODIFIER + dan + B
```

Example:

```text
dis buk bi mor gud dan dat buk.
This book is better than that book.
```

STRING does not create a special form equivalent to English `better`.

## 21. Existential statement

```text
der bi + NOUN PHRASE
```

Example:

```text
der bi buk.
There is a book. / There are books.
```

With quantity:

```text
der bi tiri buk.
There are three books.
```

## 22. Existential question

```text
bi der buk?
Is there a book? / Are there books?
```

This is ordinary question inversion.

## 23. Reflexive

```text
PRONOUN + selaf
```

Example:

```text
mi si mi selaf.
I see myself.
```

There is no special word equivalent to English `myself`.

## 24. Reciprocal

```text
wan hader
one another / each other
```

Example:

```text
de si wan hader.
They see one another.
```

## 25. Condition

```text
hif + CLAUSE, CLAUSE
```

Example:

```text
hif yu go, mi wil go.
If you go, I will go.
```

Hypothetical result:

```text
hif yu did go, mi wud go.
If you went, I would go.
```

## 26. Reason

```text
CLAUSE + bikaz + CLAUSE
```

Both sides use ordinary clause grammar.

No special subordinate verb form exists.

## 27. Result

```text
CLAUSE + so + CLAUSE
```

Again, both sides are ordinary clauses.

## 28. Content clause

```text
SUBJECT + PREDICATE + dat + CLAUSE
```

Example:

```text
mi si dat yu go.
I see that you go.
```

`dat` marks the beginning of the embedded content.

## 29. Relative clause

Object-type:

```text
buk dat mi si
book that I see
```

Subject-type:

```text
buk dat bi gud
book that is good
```

STRING does not require separate relative forms for who/which/that.

## 30. Canonical date

Written:

```text
det 2026-09-29
```

Spoken by groups:

```text
det
tun ziro tun sikas
ziro nayan
tun nayan
```

## 31. Canonical clock time

Written:

```text
tam 14:30
```

Spoken by groups:

```text
tam
wan foro
tiri ziro
```

## 32. Central rule

If a meaning can be expressed with already accepted invariant words, STRING does not invent an additional conjugation, agreement ending, or exception.

When extra information is genuinely necessary, state it explicitly.
