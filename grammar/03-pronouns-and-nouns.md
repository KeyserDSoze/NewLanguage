# 03 — Pronouns and Noun Phrases

## 1. Personal pronouns — CONFIRMED

STRING uses five core personal pronouns.

| STRING | Meaning |
|---|---|
| `mi` | I / me |
| `yu` | you, singular or plural |
| `da` | he / she / it; one third-person referent |
| `wi` | we / us |
| `de` | they / them |

These forms do not change between subject and object position.

Examples:

```text
mi si yu.
I see you.

yu si mi.
You see me.
```

## 2. No gender in the pronoun system — CONFIRMED

`da` is gender-neutral.

STRING does not require separate ordinary pronouns for English `he`, `she`, and `it`.

A speaker can add a lexical description when sex, gender, animacy, or another property matters.

## 3. No inclusive/exclusive "we" distinction — CONFIRMED

`wi` is the ordinary first-person plural pronoun.

STRING does not grammatically force the speaker to distinguish inclusive and exclusive `we`.

The distinction can be explained explicitly when needed.

## 4. Second-person number is not grammatical — CONFIRMED

`yu` addresses one or more people.

A number or quantifier can be added if the distinction matters.

## 5. Possession — WORKING STANDARD

The simplest possessive noun phrase places the possessor directly before the possessed noun.

```text
mi buk
my book

yu buk
your book

da buk
his / her / its book
```

A noun or name can occupy the same possessor position.

STRING therefore does not require separate forms equivalent to English `my/mine/me`, `your/yours/you`, and so on.

## 6. Noun number — CONFIRMED

Nouns do not change for plural.

```text
buk
book / books

sam buk
some books / some book(s)
```

Context determines number when no quantity word is present.

## 7. Articles — CONFIRMED

There is no mandatory definite or indefinite article.

English distinctions such as `a book`, `the book`, and bare `book` do not require three different STRING constructions unless the distinction is useful.

## 8. Demonstratives — CONFIRMED

STRING has two basic demonstratives:

| STRING | Meaning |
|---|---|
| `dis` | this / these |
| `dat` | that / those |

They do not change for grammatical gender or noun number.

```text
dis buk
this book / these books

dat buk
that book / those books
```

## 9. Adjectives — WORKING STANDARD

An adjective normally appears before the noun and does not agree with it.

```text
gud buk
good book / good books
```

There is no adjective agreement for gender or number.
