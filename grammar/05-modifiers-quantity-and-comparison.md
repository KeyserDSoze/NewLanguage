# 05 — Modifiers, Quantity, and Comparison

## 1. One modifier form — WORKING STANDARD

STRING does not require adjective agreement for gender or number.

A lexical modifier keeps one form.

Before a noun, it modifies the noun:

```text
gud buk
good book / good books
```

STRING does not create agreement endings.

## 2. Quantity is explicit only when useful — CONFIRMED

Nouns themselves do not mark plural.

Core quantifiers are:

| STRING | Meaning |
|---|---|
| `sam` | some |
| `hol` | all |
| `meni` | many |
| `fu` | few |
| `nan` | none |

Examples:

```text
sam buk
some books

meni buk
many books

fu buk
few books
```

Without a quantifier, `buk` can mean one book or books when context already supplies the number.

## 3. No comparative or superlative suffixes — CONFIRMED

STRING does not add endings comparable to English `-er` or `-est`.

Comparison uses independent words.

| STRING | Function |
|---|---|
| `mor` | more |
| `les` | less |
| `mos` | most |
| `lis` | least |

Examples:

```text
mor gud
better / more good

les gud
less good

mos gud
best / most good

lis gud
least good
```

The lexical adjective remains unchanged.

## 4. Comparison target — WORKING STANDARD

`dan` introduces the second term of an explicit comparison.

```text
A bi mor gud dan B.
A is better than B.
```

`dan` is derived from English `than` and is invariant.

## 5. Intensification — PROVISIONAL

STRING should prefer ordinary lexical quantity words instead of creating many grammatical degrees.

Additional intensifiers such as equivalents of `very`, `too`, and `enough` will be added as normal dictionary words rather than adjective inflections.

## 6. Adverbial use — WORKING STANDARD

STRING does not require a productive equivalent of English `-ly`.

When a modifier clearly describes a verb or clause, the same lexical form may be used without an adverbial suffix.

Word order and meaning identify what is being modified.

Lexicalized distinctions may still exist when English meanings are genuinely different, such as `good` versus `well`.
