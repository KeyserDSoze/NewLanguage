# Contributing to STRING

STRING is being designed as a small, regular universal language.

## Before proposing a rule or word

Check the proposal against these principles:

1. written form equals spoken form;
2. one symbol has one sound;
3. word shape follows `(CV)+C?`;
4. no adjacent vowels;
5. no internal consonant clusters;
6. vocabulary remains as close as practical to recognizable English pronunciation;
7. grammar avoids distinctions that do not add necessary meaning;
8. a new exception is more expensive than a slightly less English-like form.

## Vocabulary proposals

A vocabulary proposal should include:

- English lemma;
- intended sense;
- part of speech;
- reference IPA;
- proposed STRING form;
- CV segmentation;
- explanation of any phonological normalization;
- collision check.

## Grammar proposals

A grammar proposal should include:

- the communication problem being solved;
- the smallest proposed rule;
- at least three examples;
- known ambiguities;
- why an existing rule cannot already express the meaning.

Use pull requests so design decisions remain reviewable and traceable.
